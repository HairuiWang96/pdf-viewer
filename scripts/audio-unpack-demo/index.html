Audio unpack demo

Unpacks each audio file from a PDF the way the viewer does on ▶ (extractAttachments from the practice folder), and times it. Unpacking runs in one go on the page's main thread, so while it runs the page cannot update or react.

Is the page alive?

Both of these need the page's main thread. During a freeze the counter and the blue bar stop, and clicks wait, then all land at once.
